# GitLab API Web

Локальный веб-интерфейс для запросов к GitLab REST API (gitlab.com или self-hosted).

## Запуск

```bash
npm install
npm run dev        # режим разработки с автоперезапуском
# или
npm run build && npm start
```

Откройте http://127.0.0.1:4317. Порт и хост меняются переменными `PORT` / `HOST`.

## Настройка

1. Нажмите «Настройки», укажите URL инстанса (например `https://gitlab.com` или `https://gitlab.company.ru`).
2. Вставьте Personal Access Token: GitLab → Preferences → Access Tokens.
   Scope `read_api` — только чтение, `api` — чтение и запись.
3. Для self-hosted с самоподписанным сертификатом включите «Разрешить self-signed сертификат».

Настройки хранятся в `data/settings.json` (права 600). Токен не отдаётся в браузер:
запросы к GitLab выполняет локальный сервер и сам подставляет заголовок `PRIVATE-TOKEN`.

## Возможности

- Произвольные запросы: метод, путь относительно `/api/v4`, query-параметры, JSON-тело.
  В путь можно вставить полный URL или строку с `?a=1&b=2` — она разложится по полям.
- Пресеты: проекты, ветки, MR, issues, пайплайны, группы.
  Плейсхолдеры `:id`, `:merge_request_iid` и т.д. заполняются отдельно и URL-кодируются,
  поэтому ID проекта можно указать как `group/subgroup/project`.
- Пагинация по заголовкам `x-next-page` / `x-prev-page`.
- История последних 50 запросов (в localStorage браузера).
- Подтверждение перед PUT / PATCH / DELETE.

## Безопасность

Сервер слушает только `127.0.0.1`, принимает запросы только с локальным `Host` и same-origin,
а пути запросов ограничены `/api/v4` настроенного инстанса.
